
# Sprint 3 Planning

## Sprint Goal

The main goal of this sprint is to begin developing the travel planning features of our application. We will focus on allowing users to record flight information, find nearby hotels, organize transportation, and view available events at their selected destination.

## Selected Product Backlog Tasks

- PB-09 - US-05 Record Flight Details (High)
- PB-10 - US-06 Find Nearby Hotels (High)
- PB-11 - US-07 Organize Transportation (High)
- PB-12 - US-08 Show Event Menus (Medium)

## Tasks and Subtasks

### Record Flight Details

- Create a flight information screen accessible from the dashboard.
- Allow users to enter flight information such as airline, departure location, destination, dates, and ticket price.
- Allow users to save their selected flight information.
- Display saved flight details for the user to review.

### Find Nearby Hotels

- Create a hotel search screen accessible from the dashboard.
- Allow users to enter a destination to search for hotels in that area.
- Display hotel information including name, location, and estimated price.
- Allow users to select a hotel and save its information.

### Organize Transportation

- Create a transportation screen for the user's selected destination.
- Display available transportation options such as buses, trains, taxis, and rental cars.
- Allow users to view transportation details and estimated costs.
- Allow users to select and save their preferred transportation option.

### Show Event Menus

- Create an event screen that displays activities and events at the user's destination.
- Display event information such as name, date, location, and price.
- Allow users to view more details about an event.
- Allow users to select events they are interested in attending.

## Definition of Done

- A flight information screen is created and functional.
- Users can enter, save, and view flight details.
- A hotel screen is created and displays hotels for a selected destination.
- Users can select and save hotel information.
- Transportation options can be viewed and selected.
- An event screen displays activities and event information.
- Users can access the new features through the application dashboard.
- All implemented features have been tested and the code has been committed to GitHub.
