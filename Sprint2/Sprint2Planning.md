# Sprint 2 planning
## Sprint Goal
The main Goal of this sprint is to start developing a working login system for our travel planner, first we will create the login screen with password protection and require authorization

## Selected Product Backlog Tasks
- Store User Information
- Update User Information
- Require Authorization

  ## Tasks and Subtasks

  ### Create Login Screen
  - Create a login screen that will display when the application is launched.
  - The screen should have a text bar for username, password and a submit button also it should display another below the text bars that says "Create account".
    
  ### Add Create Account Functionality
  - Prompt the user to create an account if they do not already have one.
  - Have the user setup a Password and username.
  - Be able to update the users information upon request.
  - Store Username and Password of the user.
 
  ### Require User Authentication
  - Make it so to login a user must provide a correct username and password that is stored.
  - Lockout user after three incorrect attempts for 15 seconds.
  - Encrypt the Password text to increase safety.

  ## Definition of Done
  - A login screen is created and functional.
  - A user is able to create an account with a password and username.
  - The users account info is stored.
  - The user is able to change their information at their leisure.
  - Access to an account requires proper authorization using a password and username.
