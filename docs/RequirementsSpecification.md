# Agile Software Requirements Specification
Functional and Non-Functional Requirements for our Travel planning app

## Functional Requirements
### FR1 User Registration
Users should be able to register an account with a username and password.
### FR2 User Authentication
Users should be able to log out of their account and log back in by entering their username and password.
### FR3 Create Itenerary
Travelers should be able to create an itinerary and add their preferred items and it should display a total estimated trip cost after all thier preffered options are selected.
### FR4 Search Flights
Travelers will be able to search for flights to their chosen area and choose the price range they prefer.
### FR5 View Hotels
After deciding where the user is traveling, the traveler should be able to view available hotels in the area.
### FR6 Transport Options
Travelers should be able to choose their preferred mode of transport and view the transportation options available to them.
### FR7 Event Menus
Travelers should be able to view events in the area and be able to register and view pricing for those events.

## Non-Functional Requirements
### Performance
all searches should respond within 5 seconds.
### Security
all user travel info and login information should be encrypted.
### Reliability
The system availability target is 99%
### Usability
Travelers should be able to create an itinerary in about 10 mins maximum

## Constraints
- hosted in github
- Developed using scrum
- run in android studio
- 8-week development schedule
