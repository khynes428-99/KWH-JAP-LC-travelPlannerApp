# US-01 - Store User Information

As a traveler, I want to store my personal travel information so that I can easily access the information needed when planning my trips.

## Acceptance Criteria
- The user can enter and save their name.
- The user can enter and save travel document information.
- The user can enter and save relevant health information.
- Saved information can be viewed again later.
- The user can update previously saved information.
