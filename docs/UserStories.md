# US-01 - Store User Information

As a traveler, I want to store my personal travel information so that I can easily access the information needed when planning my trips.

## Acceptance Criteria
- The user can enter and save their name.
- The user can enter and save travel document information.
- The user can enter and save relevant health information.
- Saved information can be viewed again later.
- The user can update previously saved information.

## Story Points
3

# US-02 - Require Authorization

As a user authentication should be used to protect the details of my account.

## Acceptance Criteria:

- When creating an account the user should be prompted to create a username and password
- The username should be unique the the user who created it
- The user should able to use the authorization credentials to log into their account
- If a user enters a password incorrectly more then three times the password will be locked out for one minute
