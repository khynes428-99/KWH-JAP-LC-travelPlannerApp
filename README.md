# Problem Statement
Our team sets out to create a software planning tool to help people plan their upcoming trips and organize flights. This software will make finding flights, planning travel, public transport in the area, finding places in the area to stay, and planning events for the trip easier.

# Stakeholder Analysis 
This Software will be mainly useful for people planning a vacation, a business planning a retreat, or people who need to travel abroad. They would use the application to organize trip details, compare travel options, and refer back to past trips

# Key Features
Some key features of this software include:
- The ability to create an itinerary for a trip and add the travel and events the user selected.
- Organize transportation options, including bus and train routes.
- Find nearby hotels and compare Prices.
- Record flight details, including ticket prices and departure times.
- Store information from past trips for future reference.
